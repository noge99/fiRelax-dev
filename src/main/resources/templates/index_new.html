Welcome to fiRelax

the open-source fitting environment for relaxometry analysis

Fitting software with user-friendly graphical interface, that allow one to analyze Nuclear-Magnetic-Dispersion profiles using defined relaxation model. More about the models you may find here. This service was developed and is maintained within the FC-RELAX Doctoral Network.
